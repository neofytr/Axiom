Tensor API

N-dimensional tensors with refcounted storage, views, and device placement.

Types

Supported data types (ax_dtype_t):

EnumC TypeBytes
AX_FLOAT32float4
AX_FLOAT64double8
AX_INT32int32_t4
AX_INT64int64_t8
AX_UINT8uint8_t1
AX_BOOLuint8_t1

Creation

ax_tensor_t *ax_tensor_create(const int64_t *shape, int ndim, ax_dtype_t dtype)

Create a tensor with the given shape and dtype. Memory is uninitialized.

ax_tensor_t *ax_tensor_zeros(const int64_t *shape, int ndim, ax_dtype_t dtype)

Create a tensor filled with zeros.

ax_tensor_t *ax_tensor_ones(const int64_t *shape, int ndim, ax_dtype_t dtype)

Create a tensor filled with ones.

ax_tensor_t *ax_tensor_full(const int64_t *shape, int ndim, ax_dtype_t dtype, double value)

Create a tensor filled with a constant value.

ax_tensor_t *ax_tensor_from_array(const void *data, const int64_t *shape, int ndim, ax_dtype_t dtype)

Create a tensor from existing data. Copies the data into a new storage buffer.

ax_tensor_t *ax_tensor_arange(int64_t start, int64_t end, ax_dtype_t dtype)

Create a 1D tensor with values from start to end (exclusive), step 1.

ax_tensor_t *ax_tensor_rand(const int64_t *shape, int ndim, float low, float high)

Create a tensor filled with uniform random values in [low, high).

ax_tensor_t *ax_tensor_scalar(float value)

Create a scalar tensor (shape [1], 1-dim).

void ax_set_seed(unsigned int seed)

Seed the global RNG used by ax_tensor_rand and weight initializers.

Arena Creation

ax_tensor_t *ax_tensor_arena_zeros(ax_arena_t *arena, const int64_t *shape, int ndim, ax_dtype_t dtype)

Arena-allocated zero tensor. Metadata, storage, and data all come from the arena. Extremely fast (no malloc). Invalidated when the arena resets.

ax_tensor_t *ax_tensor_arena_create(ax_arena_t *arena, const int64_t *shape, int ndim, ax_dtype_t dtype)

Arena-allocated uninitialized tensor. Same lifecycle as arena_zeros but skips the memset.

Destruction

void ax_tensor_destroy(ax_tensor_t *t)

Release the tensor and its storage. Storage is freed only when refcount drops to 0.

Shape Queries

int64_t ax_tensor_numel(const ax_tensor_t *t)

Total number of elements in the tensor.

bool ax_tensor_is_contiguous(const ax_tensor_t *t)

Check if tensor data is contiguous in memory (row-major order).

Shape Manipulation

These operations are zero-copy where possible, returning views that share the same storage.

ax_tensor_t *ax_tensor_reshape(ax_tensor_t *t, const int64_t *new_shape, int new_ndim)

Reshape to new shape. Returns a view sharing storage if contiguous, otherwise copies.

ax_tensor_t *ax_tensor_transpose(ax_tensor_t *t, int dim0, int dim1)

Transpose two dimensions. Zero-copy (just swaps strides).

ax_tensor_t *ax_tensor_squeeze(ax_tensor_t *t, int dim)

Remove a dimension of size 1.

ax_tensor_t *ax_tensor_unsqueeze(ax_tensor_t *t, int dim)

Insert a dimension of size 1 at the given position.

Element Access

float ax_tensor_get_f32(const ax_tensor_t *t, const int64_t *indices)

Get a single float32 element using ndim indices.

void ax_tensor_set_f32(ax_tensor_t *t, const int64_t *indices, float value)

Set a single float32 element using ndim indices.

Views and Copies

ax_tensor_t *ax_tensor_view(ax_tensor_t *t)

Create a view that shares storage with a different shape/strides/offset.

ax_tensor_t *ax_tensor_contiguous(ax_tensor_t *t)

Make a contiguous copy of the tensor.

ax_tensor_t *ax_ensure_contiguous(ax_tensor_t *t)

Return the tensor if already contiguous, or a contiguous copy. Check if the return value differs from the input to know whether to free it.

Device Management

void ax_set_default_device(ax_device_t dev)

Set the default device for all new tensor allocations.

ax_device_t ax_get_default_device(void)

Get the current default device.

ax_tensor_t *ax_tensor_to_cuda(ax_tensor_t *t)

Move a tensor to the CUDA device. No-op if already on GPU. Returns NULL if CUDA is not available.

ax_tensor_t *ax_tensor_to_cpu(ax_tensor_t *t)

Move a tensor to CPU. No-op if already on CPU.

Operations

Binary Ops (with broadcasting)

ax_tensor_t *ax_add(ax_tensor_t *a, ax_tensor_t *b)

Element-wise addition with broadcasting.

ax_tensor_t *ax_sub(ax_tensor_t *a, ax_tensor_t *b)

Element-wise subtraction with broadcasting.

ax_tensor_t *ax_mul(ax_tensor_t *a, ax_tensor_t *b)

Element-wise multiplication with broadcasting.

ax_tensor_t *ax_div(ax_tensor_t *a, ax_tensor_t *b)

Element-wise division with broadcasting.

Unary Ops

ax_tensor_t *ax_neg(ax_tensor_t *a)

Negate all elements.

ax_tensor_t *ax_abs(ax_tensor_t *a)

Absolute value of all elements.

ax_tensor_t *ax_exp(ax_tensor_t *a)

Element-wise exponential.

ax_tensor_t *ax_log(ax_tensor_t *a)

Element-wise natural logarithm.

ax_tensor_t *ax_sqrt(ax_tensor_t *a)

Element-wise square root.

ax_tensor_t *ax_square(ax_tensor_t *a)

Element-wise square.

Scalar Ops

ax_tensor_t *ax_add_scalar(ax_tensor_t *a, double s)

Add a scalar to every element.

ax_tensor_t *ax_mul_scalar(ax_tensor_t *a, double s)

Multiply every element by a scalar.

Matrix Multiply

ax_tensor_t *ax_matmul(ax_tensor_t *a, ax_tensor_t *b)

Matrix multiplication. Both inputs must be 2D.

ax_tensor_t *ax_matmul_bias(ax_tensor_t *a, ax_tensor_t *b, ax_tensor_t *bias)

Fused matmul + bias: out = (a @ b) + bias. Single output tensor and single grad_fn. Bias may be NULL.

ax_tensor_t *ax_matmul_bias_relu(ax_tensor_t *a, ax_tensor_t *b, ax_tensor_t *bias)

Fused matmul + bias + relu: out = relu((a @ b) + bias). Applied during GEMM writeback when the backend supports it. Bias may be NULL.

Reductions

For all reductions, axis = -1 reduces everything to a scalar.

ax_tensor_t *ax_sum(ax_tensor_t *a, int axis)

Sum along the given axis.

ax_tensor_t *ax_mean(ax_tensor_t *a, int axis)

Mean along the given axis.

ax_tensor_t *ax_max(ax_tensor_t *a, int axis)

Maximum along the given axis.

ax_tensor_t *ax_min(ax_tensor_t *a, int axis)

Minimum along the given axis.

Comparison

ax_tensor_t *ax_equal(ax_tensor_t *a, ax_tensor_t *b)

Element-wise equality. Returns float tensor with 0/1 values.

ax_tensor_t *ax_greater(ax_tensor_t *a, ax_tensor_t *b)

Element-wise greater-than. Returns float tensor with 0/1 values.

Printing

void ax_tensor_print(const ax_tensor_t *t)

Print tensor shape and a few elements for debugging.

void ax_tensor_print_shape(const ax_tensor_t *t)

Print just the shape.

Storage

ax_storage_t *ax_storage_create(size_t size_bytes, ax_device_t device)

Create a new storage with the given byte count.

void ax_storage_retain(ax_storage_t *s)

Increment the storage reference count.

void ax_storage_release(ax_storage_t *s)

Decrement the reference count. Frees the storage if it hits 0.

static inline void ax_storage_touch(ax_storage_t *s)

Bump the generation counter to invalidate caches. Call on every in-place write.

Serialization

ax_status_t ax_tensor_save(ax_tensor_t *t, const char *path)

Save a single tensor to a file (raw binary with a small header).

ax_tensor_t *ax_tensor_load(const char *path)

Load a tensor from a file saved by ax_tensor_save.

Example

// create a 3x4 matrix of random values
ax_tensor_t *a = ax_tensor_rand((int64_t[]){3, 4}, 2, 0.0f, 1.0f);

// create a 4x2 matrix of ones
ax_tensor_t *b = ax_tensor_ones((int64_t[]){4, 2}, 2, AX_FLOAT32);

// matrix multiply: result is 3x2
ax_tensor_t *c = ax_matmul(a, b);
ax_tensor_print(c);

// transpose: zero-copy, just swaps strides
ax_tensor_t *ct = ax_tensor_transpose(c, 0, 1);

ax_tensor_destroy(ct);
ax_tensor_destroy(c);
ax_tensor_destroy(b);
ax_tensor_destroy(a);
