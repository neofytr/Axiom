Optimizers API

Optimizers update model parameters using their gradients. Each holds per-parameter state (momentum, Adam moments, etc.).

Creating Optimizers

All creation functions take an array of tensor pointers (the weights to optimize) and hyperparameters. The optimizer does NOT own the tensors, just references them. Per-parameter state is allocated lazily on the first step.

ax_optimizer_t *ax_sgd_create(ax_tensor_t **params, int n_params, float lr, float momentum, float weight_decay, bool nesterov)

Stochastic Gradient Descent with optional momentum and Nesterov acceleration. Set momentum to 0 for vanilla SGD.

ax_optimizer_t *ax_adam_create(ax_tensor_t **params, int n_params, float lr, float beta1, float beta2, float eps, float weight_decay)

Adam optimizer. Good defaults: lr=1e-3, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0. The most popular optimizer for general use.

ax_optimizer_t *ax_adamw_create(ax_tensor_t **params, int n_params, float lr, float beta1, float beta2, float eps, float weight_decay)

AdamW: Adam with decoupled weight decay. Better regularization than Adam's L2 penalty. Preferred for transformer training.

ax_optimizer_t *ax_rmsprop_create(ax_tensor_t **params, int n_params, float lr, float rho, float eps, float weight_decay)

RMSprop: adapts learning rate per parameter using a moving average of squared gradients. Good defaults: lr=1e-3, rho=0.99, eps=1e-8.

ax_optimizer_t *ax_adagrad_create(ax_tensor_t **params, int n_params, float lr, float eps, float weight_decay)

Adagrad: adapts learning rate based on cumulative squared gradients. Learning rate decays over time. Good for sparse gradients.

Optimizer Operations

void ax_optimizer_step(ax_optimizer_t *opt)

Update all parameters using their current gradients. Increments the global step counter.

void ax_optimizer_zero_grad(ax_optimizer_t *opt)

Zero out gradients of all parameters. Call before each forward pass in a training loop.

void ax_optimizer_set_lr(ax_optimizer_t *opt, float lr)

Set the learning rate. Useful for manual scheduling.

float ax_optimizer_get_lr(ax_optimizer_t *opt)

Get the current learning rate.

void ax_optimizer_destroy(ax_optimizer_t *opt)

Free the optimizer and its internal state. Does NOT free the parameter tensors.

Learning Rate Schedulers

Schedulers modify the optimizer's learning rate over the course of training. Starting high and decaying is almost always better than a constant LR.

ax_lr_scheduler_t *ax_sched_step_decay(ax_optimizer_t *opt, int step_size, float gamma)

Step decay: lr = initial_lr * gamma^(epoch / step_size). E.g., step_size=30, gamma=0.1 drops LR by 10x every 30 epochs.

ax_lr_scheduler_t *ax_sched_exponential(ax_optimizer_t *opt, float gamma)

Exponential decay: lr = initial_lr * gamma^epoch.

ax_lr_scheduler_t *ax_sched_cosine(ax_optimizer_t *opt, int total_steps, float min_lr)

Cosine annealing: lr = min_lr + 0.5 * (initial_lr - min_lr) * (1 + cos(pi * step / total)). Smooth decay following a cosine curve.

ax_lr_scheduler_t *ax_sched_warmup_cosine(ax_optimizer_t *opt, int warmup_steps, int total_steps, float min_lr)

Warmup + cosine: linear warmup from 0 to initial_lr, then cosine decay to min_lr. The standard schedule for transformer training.

void ax_sched_step(ax_lr_scheduler_t *sched)

Advance the scheduler by one step and update the optimizer's learning rate. Call after each epoch (or step, depending on convention).

float ax_sched_get_lr(ax_lr_scheduler_t *sched)

Get the current scheduled learning rate (for logging).

void ax_sched_destroy(ax_lr_scheduler_t *sched)

Free the scheduler. Does NOT free the optimizer.

Which Optimizer to Use

Use CaseRecommendation
General purposeax_adam_create with lr=1e-3
With weight decayax_adamw_create (decoupled is better than L2)
Fine-tuning / final trainingax_sgd_create with momentum=0.9
Sparse gradientsax_adagrad_create
RNNs / unstable trainingax_rmsprop_create

Example

// create optimizer
ax_optimizer_t *opt = ax_adam_create(
    model->params, model->n_params,
    1e-3f, 0.9f, 0.999f, 1e-8f, 0.0f);

// cosine schedule: decay to 1e-5 over 100 epochs
ax_lr_scheduler_t *sched = ax_sched_cosine(opt, 100, 1e-5f);

for (int epoch = 0; epoch < 100; epoch++) {
    // ... training loop ...
    ax_sched_step(sched);
    printf("epoch %d lr=%.6f\n", epoch, ax_sched_get_lr(sched));
}

ax_sched_destroy(sched);
ax_optimizer_destroy(opt);
