Model API

High-level model container. Wraps a network, optimizer, and loss function to provide a simple train/predict interface.

The Model Struct

typedef struct {
    ax_layer_t *net;                          // the network (usually sequential)
    ax_optimizer_t *opt;                      // optimizer (owned by model)
    ax_loss_fn_t loss_fn;                     // loss function pointer
    ax_tensor_t *params[AX_MODEL_MAX_PARAMS]; // collected parameter pointers
    int n_params;
} ax_model_t;

The model collects all trainable parameters from the layer tree at creation time and stores them in a flat array (max AX_MODEL_MAX_PARAMS = 256). This array is what you pass to the optimizer.

Creation and Compilation

ax_model_t *ax_model_create(ax_layer_t *net)

Create a model from a network layer. Collects all trainable parameters from the layer tree.

void ax_model_compile(ax_model_t *model, ax_optimizer_t *opt, ax_loss_fn_t loss_fn)

Attach an optimizer and loss function. Call before training. The model takes ownership of the optimizer. Training only

The loss function type is a function pointer: ax_tensor_t *(*ax_loss_fn_t)(ax_tensor_t *pred, ax_tensor_t *target). Pass any of the loss functions directly: ax_mse_loss, ax_cross_entropy_loss, etc.

Training

float ax_model_train_step(ax_model_t *model, ax_tensor_t *input, ax_tensor_t *target)

Single training step: forward, loss, backward, optimizer step. Returns the loss value as a float. Handles graph cleanup internally. Training only

void ax_model_fit(ax_model_t *model, ax_tensor_t *train_x, ax_tensor_t *train_y, int epochs, int print_every)

Train for multiple epochs on the full dataset. Prints loss every print_every epochs. Simple but gets the job done for small datasets that fit in memory. Training only

Inference

ax_tensor_t *ax_model_predict(ax_model_t *model, ax_tensor_t *input)

Forward pass only (inference). Switches to eval mode, runs forward, switches back. Does not track gradients.

Serialization

ax_status_t ax_model_save(ax_model_t *model, const char *path)

Save a sequential model to a binary file. Writes architecture and all parameter data. Format: little-endian, fixed-size header, compact.

ax_model_t *ax_model_load(const char *path)

Load a model from a binary file. Reconstructs the layer tree and loads all weights. Returns NULL on failure.

Utilities

void ax_model_summary(ax_model_t *model)

Print model summary (delegates to ax_layer_summary).

void ax_model_destroy(ax_model_t *model)

Destroy the model, its optimizer, its network, and all owned tensors.

Data Loading

Axiom provides a data pipeline for batching and shuffling training data.

Datasets

ax_dataset_t *ax_tensor_dataset_create(ax_tensor_t *inputs, ax_tensor_t *targets)

Wrap a pair of tensors as a dataset. First dimension is the sample dimension.

ax_dataset_t *ax_csv_dataset_load(const char *path, const int *feature_cols, int n_features, const int *target_cols, int n_targets, bool has_header)

Load a CSV file as a dataset. Specify which columns are features and which are targets. All values parsed as float32.

DataLoader

ax_dataloader_t *ax_dataloader_create(ax_dataset_t *dataset, int64_t batch_size, bool shuffle)

Create a dataloader for batched iteration over a dataset.

void ax_dataloader_reset(ax_dataloader_t *dl)

Reset to the start of the dataset. Reshuffles if shuffle=true.

bool ax_dataloader_next(ax_dataloader_t *dl, ax_batch_t *batch)

Get the next batch. Returns false when the epoch is done. Batch tensors are freshly allocated; caller must destroy them.

int64_t ax_dataloader_num_batches(ax_dataloader_t *dl)

Number of batches in one epoch.

void ax_dataloader_destroy(ax_dataloader_t *dl)

Free the dataloader. Does NOT free the dataset.

Transforms

ax_tensor_t *ax_transform_normalize(ax_tensor_t *t)

Normalize to zero mean, unit variance along axis 0 (per-feature).

ax_tensor_t *ax_transform_normalize_with(ax_tensor_t *t, ax_tensor_t *mean, ax_tensor_t *std)

Normalize with known mean and std (for applying training stats to test data).

ax_tensor_t *ax_transform_one_hot(ax_tensor_t *labels, int num_classes)

One-hot encode integer labels. Input: [n] of ints in [0, num_classes). Output: [n, num_classes] of float 0/1.

ax_tensor_t *ax_transform_minmax_scale(ax_tensor_t *t)

Min-max scaling to [0, 1] range along axis 0.

Example: Full Pipeline

ax_init();

// build network
ax_layer_t *net = ax_sequential_create();
ax_sequential_add(net, ax_dense_create(784, 256, true));
ax_sequential_add(net, ax_relu_layer_create());
ax_sequential_add(net, ax_dropout_create(0.3f));
ax_sequential_add(net, ax_dense_create(256, 10, true));

// create model and compile
ax_model_t *m = ax_model_create(net);
ax_model_summary(m);

ax_optimizer_t *opt = ax_adam_create(
    m->params, m->n_params,
    1e-3f, 0.9f, 0.999f, 1e-8f, 0);
ax_model_compile(m, opt, ax_cross_entropy_loss);

// train
ax_model_fit(m, train_x, train_y, 50, 5);

// save and load
ax_model_save(m, "model.axm");
ax_model_destroy(m);

ax_model_t *loaded = ax_model_load("model.axm");
ax_tensor_t *pred = ax_model_predict(loaded, test_x);

ax_tensor_destroy(pred);
ax_model_destroy(loaded);
ax_shutdown();
