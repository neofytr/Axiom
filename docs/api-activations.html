Activations API

Activation functions with autograd support. All return new tensors with gradients tracked.

Basic Activations

These live in ops.h and are the most commonly used.

ax_tensor_t *ax_relu(ax_tensor_t *a)

ReLU: max(0, x). The workhorse activation for hidden layers.

ax_tensor_t *ax_sigmoid(ax_tensor_t *a)

Sigmoid: 1 / (1 + exp(-x)). Squashes output to (0, 1).

ax_tensor_t *ax_tanh_op(ax_tensor_t *a)

Tanh: (exp(x) - exp(-x)) / (exp(x) + exp(-x)). Output in (-1, 1).

In-Place Variants

These mutate the input buffer directly when the storage refcount is 1 (no shared views), halving memory traffic. If refcount > 1, they fall back to the non-inplace variant for safety. Autograd-compatible: backward works with the post-activation values.

ax_tensor_t *ax_relu_inplace(ax_tensor_t *a)

In-place ReLU. Returns the same tensor pointer.

ax_tensor_t *ax_sigmoid_inplace(ax_tensor_t *a)

In-place sigmoid.

ax_tensor_t *ax_tanh_inplace(ax_tensor_t *a)

In-place tanh.

Extended Activations

These live in activations.h.

ax_tensor_t *ax_leaky_relu(ax_tensor_t *a, float alpha)

Leaky ReLU: max(alpha * x, x). Typical alpha is 0.01. Prevents dead neurons by allowing a small gradient for negative inputs.

ax_tensor_t *ax_elu(ax_tensor_t *a, float alpha)

ELU: x if x > 0, alpha * (exp(x) - 1) otherwise. Smooth approximation to ReLU with negative values.

ax_tensor_t *ax_selu(ax_tensor_t *a)

SELU: scale * elu(x, alpha) with specific constants for self-normalizing networks. Use with ax_init_lecun_normal.

ax_tensor_t *ax_gelu(ax_tensor_t *a)

GELU (approximate): x * 0.5 * (1 + tanh(sqrt(2/pi) * (x + 0.044715 * x^3))). Used in transformers.

ax_tensor_t *ax_swish(ax_tensor_t *a)

Swish (SiLU): x * sigmoid(x). Self-gated activation.

ax_tensor_t *ax_softplus(ax_tensor_t *a)

Softplus: log(1 + exp(x)). Smooth approximation to ReLU.

ax_tensor_t *ax_mish(ax_tensor_t *a)

Mish: x * tanh(softplus(x)). Self-regularizing, non-monotonic.

ax_tensor_t *ax_softmax(ax_tensor_t *a, int axis)

Softmax along a given axis. Numerically stable (subtracts max first). axis = -1 means last dimension.

Which Activation to Use

Use CaseRecommendation
Default hidden layersax_relu (fast, well-understood)
Dead neuron problemsax_leaky_relu or ax_elu
Transformer modelsax_gelu
Self-normalizing netsax_selu with LeCun init
Modern architecturesax_swish or ax_mish
Output (classification)ax_softmax (or use cross-entropy loss which applies it internally)
Output (binary)ax_sigmoid (or use BCE with logits loss)

Example

// functional style (direct tensor ops)
ax_tensor_t *h1 = ax_matmul(input, w1);
ax_tensor_t *a1 = ax_gelu(h1);

// or use the fused variant for performance
ax_tensor_t *a2 = ax_matmul_bias_relu(input, w1, b1);

// or use in-place when you know the tensor is unique
ax_tensor_t *h = ax_matmul_bias(input, w1, b1);
ax_relu_inplace(h);  // modifies h, returns same pointer
