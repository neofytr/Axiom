Autograd API

Reverse-mode automatic differentiation. Records operations during the forward pass, then walks backward through the computation graph to compute gradients.

Core Functions

ax_status_t ax_backward(ax_tensor_t *loss)

Run the backward pass starting from the loss tensor. The tensor should be a scalar (1 element). Computes gradients for all tensors in the graph that have requires_grad = true. Training only

void ax_zero_grad(ax_tensor_t *t)

Zero out the gradient of a single tensor. Usually you will use ax_optimizer_zero_grad() instead, which zeros all parameter gradients at once. Training only

void ax_graph_cleanup(ax_tensor_t *root)

Free the computation graph reachable from the root tensor. Destroys all intermediate (non-leaf) tensors created during the forward pass. Leaf tensors (parameters, user-created) are NOT destroyed. The root tensor itself is NOT destroyed. Training only

Always call ax_graph_cleanup(loss) after ax_backward(loss) and ax_optimizer_step(opt). Without it, all intermediate forward-pass tensors will leak.

Gradient Context

void ax_no_grad(void)

Disable gradient tracking. Operations after this call will not record into the computation graph. Useful during inference for performance.

void ax_enable_grad(void)

Re-enable gradient tracking after ax_no_grad().

bool ax_grad_enabled(void)

Check if gradient tracking is currently enabled.

Arenas

ax_arena_t *ax_backward_arena(void)

Get the thread-local backward scratch arena. Backward functions use this for temporary buffers that are freed in bulk after ax_backward() completes. Do NOT store arena pointers in grad_fn->saved[].

ax_arena_t *ax_forward_arena(void)

Get the thread-local forward scratch arena. Used for tensors that must outlive the forward pass and stay alive through backward (e.g., batchnorm's saved x_hat). Reset by ax_graph_cleanup(), NOT by ax_backward().

Grad Fn Management

ax_grad_fn_t *ax_grad_fn_create(ax_backward_fn_t fn)

Allocate a grad_fn from the thread-local slab free-list. Fast (pointer bump, no malloc).

void ax_grad_fn_destroy(ax_grad_fn_t *gf)

Return a grad_fn to the thread-local slab free-list.

Testing

double ax_grad_check(ax_tensor_t *(*forward_fn)(ax_tensor_t *input), ax_tensor_t *input, double eps)

Numerical gradient check. Compares analytical gradient (from autograd) against finite-difference approximation. Returns the max absolute difference. Use this in tests to verify that your backward implementations are correct.

Memory

ax_arena_t *ax_arena_create(size_t block_size)

Create a new arena with the given default block size. Pass 0 for the default (1 MB).

void *ax_arena_alloc(ax_arena_t *arena, size_t size, size_t alignment)

Allocate bytes from the arena with the given alignment. Fast bump-pointer allocation.

void ax_arena_reset(ax_arena_t *arena)

Reset the arena, marking all memory as free without releasing it. Subsequent allocations reuse existing blocks.

void ax_arena_destroy(ax_arena_t *arena)

Destroy the arena and free all blocks.

Typical Training Loop Pattern

for (int step = 0; step < n_steps; step++) {
    // 1. zero gradients
    ax_optimizer_zero_grad(opt);

    // 2. forward pass (records computation graph)
    ax_tensor_t *pred = ax_layer_forward(net, input);
    ax_tensor_t *loss = ax_cross_entropy_loss(pred, target);

    // 3. backward pass (computes gradients)
    ax_backward(loss);

    // 4. optional gradient clipping
    ax_clip_grad_norm(params, n_params, 1.0f);

    // 5. update weights
    ax_optimizer_step(opt);

    // 6. clean up computation graph (frees intermediates)
    ax_graph_cleanup(loss);
    ax_tensor_destroy(loss);
}

How requires_grad Works

Set t->requires_grad = true on any tensor to track gradients for it. Layer creation functions do this automatically for weight and bias tensors. When an operation sees at least one input with requires_grad = true and gradient tracking is enabled, it creates a grad_fn and attaches it to the output tensor.

During ax_backward(), gradients flow back through the graph and accumulate in t->grad for every tensor with requires_grad = true.

Inference Mode

For pure inference, you have two options:

  • Call ax_no_grad() before inference and ax_enable_grad() after. This skips all grad_fn allocation during forward passes.
  • Build with -DAX_INFERENCE_ONLY=ON. This compiles out all autograd code entirely. ax_grad_enabled() always returns false, and ax_grad_fn_create() always returns NULL.
