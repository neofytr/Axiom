Building

CMake flags, build profiles, and cross-compilation.

Default Build

mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
make -j$(nproc)
ctest --output-on-failure

This produces libaxiom.a (or .so) and all test binaries. The build auto-detects your CPU features and enables the best available GEMM backend.

CMake Flags

Flag Default Description
AX_CPU_ISA_DISPATCH ON Builds AVX-512 + AVX2 + scalar paths. Picks fastest at runtime via CPUID.
AX_CUDA OFF Enables the CUDA backend. Requires the CUDA toolkit (nvcc on PATH).
AX_INFERENCE_ONLY OFF Strips all training code (autograd, optimizers, losses). Binary under 100KB on ARM.
AX_PROFILE (none) Build profile for target environment. See profiles below.
AX_COUNT_ALLOCS OFF Enables allocation counting for memory profiling.

Build Profiles

embedded-linux

Reduced buffer sizes, trimmed for embedded Linux targets (Raspberry Pi, Jetson Nano, etc.).

cmake -DCMAKE_BUILD_TYPE=Release -DAX_PROFILE=embedded-linux ..

embedded-baremetal

No stdio, no heap, no threads. Designed for Cortex-M class microcontrollers. Must be combined with AX_INFERENCE_ONLY=ON.

cmake -DCMAKE_BUILD_TYPE=MinSizeRel \
      -DAX_PROFILE=embedded-baremetal \
      -DAX_INFERENCE_ONLY=ON \
      -DCMAKE_TOOLCHAIN_FILE=your-cortexm-toolchain.cmake ..

CUDA Build

cmake -DCMAKE_BUILD_TYPE=Release -DAX_CUDA=ON ..
make -j$(nproc)

The CUDA backend registers itself at ax_compute_init() time. To route all ops to the GPU:

ax_set_default_device(AX_DEVICE_CUDA);
ax_compute_set_backend(AX_BACKEND_CUDA);

Cross-Compilation

For ARM cross-compilation from x86:

cmake -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_C_COMPILER=aarch64-linux-gnu-gcc \
      -DCMAKE_SYSTEM_NAME=Linux \
      -DCMAKE_SYSTEM_PROCESSOR=aarch64 ..

The build system detects the target architecture and selects the right GEMM micro-kernel (NEON 8x12 for aarch64, AVX-512/AVX2 for x86).

Debug Builds

# with address sanitizer
cmake -DCMAKE_BUILD_TYPE=Debug \
      -DCMAKE_C_FLAGS="-fsanitize=address -fno-omit-frame-pointer" ..

# with thread sanitizer
cmake -DCMAKE_BUILD_TYPE=Debug \
      -DCMAKE_C_FLAGS="-fsanitize=thread" ..

All 22 tests pass under both ASan and TSan.

Linking

After building, link against the static library:

gcc -O2 -I/path/to/include your_code.c -L/path/to/build -laxiom -lm -lpthread -o your_binary

If OpenMP is enabled (it is by default when available), add -fopenmp to both compile and link flags.
