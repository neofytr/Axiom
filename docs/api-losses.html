Losses API

Loss functions for training. Each returns a scalar tensor (1 element) suitable for ax_backward().

Regression Losses

ax_tensor_t *ax_mse_loss(ax_tensor_t *pred, ax_tensor_t *target)

Mean Squared Error: (1/n) * sum((pred - target)^2). The classic regression loss. Penalizes large errors heavily due to the squaring.

ax_tensor_t *ax_mae_loss(ax_tensor_t *pred, ax_tensor_t *target)

Mean Absolute Error: (1/n) * sum(|pred - target|). More robust to outliers than MSE.

ax_tensor_t *ax_huber_loss(ax_tensor_t *pred, ax_tensor_t *target, float delta)

Huber loss (smooth L1): quadratic for small errors (|x| <= delta), linear for large. Best of both worlds: smooth gradients near zero (like MSE) and robust to outliers (like MAE).

Classification Losses

ax_tensor_t *ax_cross_entropy_loss(ax_tensor_t *pred, ax_tensor_t *target)

Cross-entropy loss for multi-class classification. pred should be raw logits (NOT softmax'd); log-softmax is applied internally for numerical stability. target is one-hot encoded. Shapes: pred [batch, classes], target [batch, classes].

The backward pass for cross-entropy computes softmax(pred) - target in a single SIMD pass, avoiding the full softmax Jacobian.

ax_tensor_t *ax_bce_with_logits_loss(ax_tensor_t *pred, ax_tensor_t *target)

Binary cross-entropy with logits. pred is raw logits (before sigmoid). Target is 0 or 1. Uses the numerically stable formulation: mean(max(pred, 0) - pred*target + log(1 + exp(-|pred|))).

Which Loss to Use

TaskLoss Function
Regression (continuous output)ax_mse_loss
Regression with outliersax_huber_loss or ax_mae_loss
Multi-class classificationax_cross_entropy_loss
Binary classificationax_bce_with_logits_loss
Multi-label classificationax_bce_with_logits_loss (per label)

Example

// classification: raw logits in, cross-entropy handles softmax
ax_tensor_t *logits = ax_layer_forward(net, input);
ax_tensor_t *loss = ax_cross_entropy_loss(logits, one_hot_labels);

// backward + update
ax_backward(loss);
ax_optimizer_step(opt);
ax_graph_cleanup(loss);
ax_tensor_destroy(loss);

// regression with huber loss (delta=1.0)
ax_tensor_t *pred = ax_layer_forward(net, input);
ax_tensor_t *loss = ax_huber_loss(pred, targets, 1.0f);
