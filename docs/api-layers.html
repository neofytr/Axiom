Layers API

Building blocks for composing neural networks. Layers have forward functions, track parameters, and switch between train/eval mode.

Dense (Fully Connected)

ax_layer_t *ax_dense_create(int64_t in_features, int64_t out_features, bool use_bias)

Create a dense layer: out = input @ weight + bias. Weights initialized with Kaiming uniform by default.

Weight shape: [in_features, out_features]. Bias shape: [out_features] (or NULL if use_bias is false).

Conv2D

ax_layer_t *ax_conv2d_create(int in_channels, int out_channels, int kernel_size, int stride, int padding, bool use_bias)

Create a 2D convolution layer with square kernels. Data layout is NCHW throughout.

ax_layer_t *ax_conv2d_create_ex(int in_channels, int out_channels, int kernel_h, int kernel_w, int stride_h, int stride_w, int pad_h, int pad_w, bool use_bias)

Create a Conv2D with non-square kernel, stride, and padding.

Input: [N, C_in, H, W]. Output: [N, C_out, H_out, W_out] where H_out = (H + 2*padding - kernel_size) / stride + 1.

Pooling

ax_layer_t *ax_maxpool2d_create(int kernel_size, int stride, int padding)

Max pooling: takes the max value in each kernel-sized window. Saves argmax positions for backward pass.

ax_layer_t *ax_avgpool2d_create(int kernel_size, int stride, int padding)

Average pooling: averages values in each window.

ax_layer_t *ax_global_avgpool2d_create(void)

Global average pooling: average each channel to a single value. Input [N, C, H, W] to output [N, C].

Normalization

ax_layer_t *ax_batchnorm_create(int64_t num_features, float eps, float momentum)

Batch normalization. Normalizes each feature across the batch, then applies learnable scale (gamma) and shift (beta). Maintains running stats for inference. Input: [batch, features].

ax_layer_t *ax_layernorm_create(int64_t num_features, float eps)

Layer normalization. Normalizes across features for each sample independently. No running stats needed. Input: [batch, features].

Dropout

ax_layer_t *ax_dropout_create(float p)

Dropout layer. Training: zeros elements with probability p, scales rest by 1/(1-p). Eval: identity pass-through.

Utility Layers

ax_layer_t *ax_flatten_create(void)

Flatten spatial dimensions: [N, C, H, W] to [N, C*H*W]. Needed to connect conv layers to dense layers.

Activation Layers

Stateless wrappers around the activation functions. These let you put activations in a sequential model.

ax_layer_t *ax_relu_layer_create(void)

ReLU activation layer.

ax_layer_t *ax_sigmoid_layer_create(void)

Sigmoid activation layer.

ax_layer_t *ax_tanh_layer_create(void)

Tanh activation layer.

ax_layer_t *ax_leaky_relu_layer_create(float alpha)

Leaky ReLU layer. Typical alpha: 0.01.

ax_layer_t *ax_elu_layer_create(float alpha)

ELU activation layer.

ax_layer_t *ax_gelu_layer_create(void)

GELU activation layer (approximate version).

ax_layer_t *ax_swish_layer_create(void)

Swish (SiLU) activation layer.

ax_layer_t *ax_softmax_layer_create(int axis)

Softmax layer along given axis.

Sequential Model

ax_layer_t *ax_sequential_create(void)

Create an empty sequential model. Chains layers together; forward pass runs input through each layer in order.

ax_layer_t *ax_sequential_add(ax_layer_t *seq, ax_layer_t *layer)

Add a layer to the sequential model. Returns the model for chaining. Max 64 layers (AX_SEQ_MAX_LAYERS).

Fusion

ax_layer_t *ax_sequential_fuse(ax_layer_t *model)

Walk a sequential model and replace every Conv2D + BatchNorm + ReLU triple with a fused layer. Mutates in-place, returns the same pointer. Safe to call multiple times.

Common Layer Operations

ax_tensor_t *ax_layer_forward(ax_layer_t *layer, ax_tensor_t *input)

Run the forward pass through the layer.

int ax_layer_get_params(ax_layer_t *layer, ax_tensor_t **params, int max_params)

Collect all trainable parameters (recursive for sequential). Fills params array, returns count.

int ax_layer_get_buffers(ax_layer_t *layer, ax_tensor_t **buffers, int max_buffers)

Collect all non-trainable buffers (e.g., batchnorm running stats). Recursive for sequential.

void ax_layer_train(ax_layer_t *layer)

Set train mode (recursive for sequential). Affects dropout and batchnorm behavior.

void ax_layer_eval(ax_layer_t *layer)

Set eval mode (recursive for sequential). Dropout becomes identity, batchnorm uses running stats.

void ax_layer_summary(ax_layer_t *layer)

Print model summary: layer types, shapes, and parameter counts.

int64_t ax_layer_param_count(ax_layer_t *layer)

Count total trainable parameters.

void ax_layer_destroy(ax_layer_t *layer)

Free a layer and all its owned tensors.

Gradient Clipping

void ax_clip_grad_value(ax_tensor_t **params, int n_params, float max_val)

Clip gradient values to [-max_val, max_val].

float ax_clip_grad_norm(ax_tensor_t **params, int n_params, float max_norm)

Clip gradient norm. Returns the original norm before clipping.

Weight Initialization

void ax_init_xavier_uniform(ax_tensor_t *t, int64_t fan_in, int64_t fan_out)

Xavier/Glorot uniform: U[-limit, limit] where limit = sqrt(6 / (fan_in + fan_out)). Good for sigmoid/tanh.

void ax_init_xavier_normal(ax_tensor_t *t, int64_t fan_in, int64_t fan_out)

Xavier/Glorot normal: N(0, std) where std = sqrt(2 / (fan_in + fan_out)).

void ax_init_kaiming_uniform(ax_tensor_t *t, int64_t fan_in)

He/Kaiming uniform: U[-limit, limit] where limit = sqrt(6 / fan_in). Designed for ReLU.

void ax_init_kaiming_normal(ax_tensor_t *t, int64_t fan_in)

He/Kaiming normal: N(0, std) where std = sqrt(2 / fan_in).

void ax_init_lecun_normal(ax_tensor_t *t, int64_t fan_in)

LeCun normal: N(0, 1/sqrt(fan_in)). For SELU activations.

void ax_init_uniform(ax_tensor_t *t, float low, float high)

Uniform random in [low, high).

void ax_init_normal(ax_tensor_t *t, float mean, float std)

Normal/Gaussian with given mean and std.

void ax_init_zeros(ax_tensor_t *t)

Fill with zeros.

void ax_init_ones(ax_tensor_t *t)

Fill with ones.

void ax_init_constant(ax_tensor_t *t, float value)

Fill with a constant value.

Example: CNN

ax_layer_t *net = ax_sequential_create();

// conv block 1
ax_sequential_add(net, ax_conv2d_create(1, 32, 3, 1, 1, true));
ax_sequential_add(net, ax_batchnorm_create(32, 1e-5f, 0.1f));
ax_sequential_add(net, ax_relu_layer_create());
ax_sequential_add(net, ax_maxpool2d_create(2, 2, 0));

// conv block 2
ax_sequential_add(net, ax_conv2d_create(32, 64, 3, 1, 1, true));
ax_sequential_add(net, ax_batchnorm_create(64, 1e-5f, 0.1f));
ax_sequential_add(net, ax_relu_layer_create());
ax_sequential_add(net, ax_maxpool2d_create(2, 2, 0));

// classifier head
ax_sequential_add(net, ax_flatten_create());
ax_sequential_add(net, ax_dense_create(64 * 7 * 7, 128, true));
ax_sequential_add(net, ax_relu_layer_create());
ax_sequential_add(net, ax_dropout_create(0.5f));
ax_sequential_add(net, ax_dense_create(128, 10, true));

// optionally fuse conv+bn+relu triples
ax_sequential_fuse(net);
